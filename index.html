Shortcuts

Ctrl+Enter
Apply the Query editor to the canvas
Ctrl+Z
Undo a canvas change
Ctrl+Shift+Z
Redo
Ctrl+V
On the canvas: build blocks from a copied query
Arrow keys
On a block's title bar: move the block (hold Shift for bigger steps)
Ctrl+D
On a block's title bar: duplicate the block
Delete
On a block's title bar: remove the block

Concepts

Block
One query block: which entity to start from, its fields, filters and settings.
Variables tab
Values passed with the query as $name. Use them as filter values with the $ button on a condition.
Use as variable
In Settings: the block becomes name as var(…). It isn't returned; other blocks can Start from its nodes or filter with uid(name). The blue arrows show these links.
Incomplete conditions
A filter condition without a value is marked and left out of the query until you finish it.
